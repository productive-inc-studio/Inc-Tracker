นโยบายความเป็นส่วนตัว

INC WorkTracker · มีผลตั้งแต่ 17 ตุลาคม 2026

INC WorkTracker เป็นระบบติดตามงานภายในของทีม INC Studio ใช้ได้เฉพาะสมาชิกที่ได้รับเชิญหรืออนุมัติจากผู้ดูแลระบบเท่านั้น หน้านี้อธิบายว่าเราเก็บข้อมูลอะไร ใช้อย่างไร และคุณมีสิทธิ์อะไรบ้าง

ข้อมูลที่เราเก็บ

  • ข้อมูลจากบัญชี Google เมื่อคุณเข้าสู่ระบบ: ชื่อ อีเมล และรูปโปรไฟล์ เราไม่ได้รับรหัสผ่าน และไม่เข้าถึงอีเมล ไฟล์ หรือข้อมูลอื่นในบัญชี Google ของคุณ
  • ข้อมูลการทำงาน ที่คุณหรือเพื่อนร่วมทีมบันทึก: งาน รายละเอียดงาน กำหนดส่ง สถานะ เวลาที่จับหรือบันทึกไว้ และคอมเมนต์
  • ข้อมูลที่จำเป็นต่อการเข้าสู่ระบบ เช่น session token ที่เก็บในเบราว์เซอร์ของคุณ

เราใช้ข้อมูลเพื่อ

  • ยืนยันตัวตนและกำหนดสิทธิ์การเข้าถึง (Admin / Lead / Member)
  • แสดงงาน มอบหมายงาน และคำนวณสรุปผลงานรายเดือน เช่น จำนวนงานที่ปิด ชั่วโมงทำงาน และอัตราการส่งตรงเวลา
  • ส่งแจ้งเตือนเกี่ยวกับงาน (ชื่องาน ผู้รับผิดชอบ กำหนดส่ง) เข้ากลุ่ม LINE ของทีม เมื่อ Admin หรือ Lead เป็นผู้สั่งส่ง

เราไม่ขาย ไม่ให้เช่า และไม่ใช้ข้อมูลของคุณเพื่อโฆษณา

ใครเห็นข้อมูลของคุณ

  • สมาชิกในทีมเห็นชื่อและรูปโปรไฟล์ของกันและกัน
  • Member เห็นเฉพาะงานที่ตนเองรับผิดชอบหรือสร้าง ส่วน Admin และ Lead เห็นงานและเวลาทำงานของทั้งทีม
  • ผู้ให้บริการที่ระบบใช้งาน ได้แก่ Supabase (ฐานข้อมูลและการยืนยันตัวตน), GitHub Pages (โฮสต์หน้าเว็บ), Google (การเข้าสู่ระบบ) และ LINE (ข้อความแจ้งเตือน) ซึ่งประมวลผลข้อมูลเท่าที่จำเป็นต่อการให้บริการ

ข้อมูลจาก Google

การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google APIs ของ INC WorkTracker เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use โดยเราใช้เพียงชื่อ อีเมล และรูปโปรไฟล์ เพื่อเข้าสู่ระบบและแสดงตัวตนของคุณในทีมเท่านั้น

การเก็บรักษาและการลบข้อมูล

ข้อมูลถูกเก็บไว้ตลอดช่วงที่คุณเป็นสมาชิกทีม เมื่อถูกปิดการเข้าถึง ประวัติงานและเวลาทำงานจะยังถูกเก็บไว้เพื่อใช้ในรายงานย้อนหลังของทีม คุณขอดู แก้ไข หรือลบข้อมูลส่วนตัวได้โดยติดต่อผู้ดูแลระบบตามช่องทางด้านล่าง

ความปลอดภัย

การเชื่อมต่อทั้งหมดเข้ารหัสด้วย HTTPS และสิทธิ์การเข้าถึงข้อมูลถูกบังคับที่ระดับฐานข้อมูล (Row Level Security) ผู้ที่ไม่ได้เข้าสู่ระบบหรือยังไม่ได้รับอนุมัติจะเข้าถึงข้อมูลไม่ได้

การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลง เราจะปรับปรุงหน้านี้และวันที่มีผลด้านบน
